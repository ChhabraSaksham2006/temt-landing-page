# TEMT - Enterprise Carbon Accounting Platform

The official landing page for **TEMT (Transport Emissions Management Tool)**, the one-stop platform for enterprise carbon accounting. Designed specifically to convince accounting managers at NIFTY 500 companies that TEMT is the ultimate, compliance-ready system of record for logistics emissions.

## 🚀 Overview

TEMT positions itself as a financial-grade ERP for carbon data rather than just a sustainability calculator. It replaces manual vendor data collection, fragmented tools, and messy spreadsheets with a single auditable platform.

### Key Sections:
- **Hero & Value Prop**: High-impact messaging ("Stop estimating emissions. Start accounting for them.")
- **Trust & Social Proof**: Methodology validated by IIM Bangalore and dynamic enterprise testimonials.
- **Product Experience**: Interactive dashboard skeletons (Road Transport, Emissions Ledger, BRSR Reports, etc.).
- **Accounting Estimator**: Dynamic ROI calculator based on Monthly Shipments and Data Complexity.
- **Enterprise Capabilities**: Exception management, high-volume automated reconciliation, and automated month-end close.

## 🛠️ Technology Stack

- **Framework**: Next.js (React)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Inter (Google Fonts)

## 💻 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ChhabraSaksham2006/temt-landing-page.git
   ```
2. Navigate to the project directory:
   ```bash
   cd temt-landing-page
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📱 Responsive Design

This landing page is fully responsive, featuring optimized mobile paddings, scrollable horizontal tab bars, and intelligent grid collapse configurations (e.g., footer and complex metrics grids collapsing seamlessly on smaller viewports).

## 🔒 Security & Compliance

Designed to reflect strict enterprise security standards, including SOC2 Type II, ISO 27001, and GDPR compliance, along with BRSR-ready reporting capabilities tailored for the Indian enterprise market.
